# 开发决定与正式冻结前声明

2026-10-12。此决定在任何 1600000 段正式世界运行前写入。

- 第一批：1500000–1500003，2 个继承初始化，6 条件 × 6 场景，288 条生命。
- 第二批：1500100–1500107，2 个初始化，6 条件 × 稳定/组合场景，192 条生命。
- 两批共 12 个不同开发世界。学习算法和超参数没有在两批之间修改；第二批仅聚焦组合场景与稳定保护，主观察转向 R10−R00。
- 第一批 R10−R00 组合损失差 −0.243430，第二批 −0.121477；12 个世界的配对差均为负。合并开发差 −0.162128，配对标准差 0.145190。
- R11 与 RT 的方向在两批之间反转。G 的额外收益尚不稳定，不把其更复杂的结构预设为最终候选。

正式首要问题：R10 在组合挑战窗口的平均身体损失，是否较 R00 改善。R10 仅开启关系读取；R00 是保留原 C 动作行为的影子关系对照。首要比较为 R10−R00，小于零更好。

最小有用下降设为 0.05。这个值不同于上一轮 0.01：本轮目标是验证具有实际幅度的环境适应收益，不声称能够精确分辨细小效果。开发标准差乘 1.25 作规划余量，用双侧 5%、80% 功效正态近似得到约 104 个世界；正式采用 128 个世界。小开发样本的方差估计可能偏低，以上不是实际功效保证。

预先指定成功判据：首要差点估计不高于 −0.05，且 95% 世界配对区间上界小于 0；同时稳定环境身体损失差的上界不超过 +0.02、存活差的下界不低于 −0.02。对原 A、G 额外贡献、固定温度、其他场景和干预结果分别报告，不把未校正次级区间当作独立确认性发现。整体版本推荐还要考察相对于原 A 的实际结果和机制限制。

三个独立队列全部在观察正式结果前冻结：
1. 主验证：1600000–1600127；初始化 0、1；A/R00/R10/R01/R11/RT；r_stable/r_combined；每条 2560 步，共 3072 条生命。
2. 场景验证：1601000–1601015；同两初始化与六条件；r_block/r_noise/r_reopen/r_relocate；每条 2560 步，共 768 条生命。
3. 长生命：1602000–1602015；同两初始化；R00/R10；r_combined；每条 5120 步，共 64 条生命。它检验同一生命在既定事件后的持续表现，后半段不额外重置身体，也不新增挑战；所有早死者仍在分母内。

正式合计 3904 条生命，10,158,080 次主生命转移，不含诊断分支。统计单位是世界；两个固定初始化先在世界内平均。不同队列不混成同一个配对样本。

参数保留开发值：关系更新率 0.45，向环形先验恢复的时间尺度 256，最小概率 0.04；G 初始权重 0.9，固定温度 RT 为 0.9；动作学习率 0.001，其余原 C 设置不变。RT 与 G 初始权重相同，开发组合场景平均熵较接近，但不宣称跨世界逐步严格匹配。

主队列前 12 个世界及场景队列前 8 个世界执行预定事件触发诊断：R10/R11 在同一有向位置第三次实际受阻后、仍存活且剩余预算充足时，最多产生一个检查点；保留所有未触发情况。四分支各最多 96 步，动作参数学习率为零，其他经历学习保持一致。另一条边的等幅干预不保证功能无关。

代码、协议、配置、种子、观察窗口、停止规则与原始日志在每个队列起跑前锁定。失败和未触发事件者不剔除，不为获得显著性追加正式样本。默认 A 继续作为兼容入口；正式完成后依据证据说明推荐的明确运行配置，不静默改变既有检查点语义。
