# WUYU 下一步：让经历能够被复验、修订，并支持新的可能性

日期：2026-10-12（Asia/Shanghai）

状态：研究与实施建议；尚未启动新一轮正式实验，也未验证文中的新方法。承接已完成的持续状态与经历干预实验。下文的参数数值是拟议设计，实施时须在正式留出前确认并冻结。

## 一、我的主判断

下一步应研究一个具体问题：个体怎样根据已有经历行动，又怎样取得足以修正这些经历的新证据。

这包含两种不同能力：旧办法失效后能够纠错；旧办法尚可使用时仍有机会发现更好的办法。后一种情况可能完全没有当前预测错误，因此只增加“出错后探索”不够。

工程上先完成一轮有边界的机制诊断和验证；理论上同步记录新增机制承担了什么解释责任。随后推进可保留的外部成果、技能和可达结果扩展，避免将整个物欲路线长期停留在固定目标的控制任务中。

## 二、现有证据支持到哪里

最近实验的独立个体单位为世界／代理种子，32 个开发、128 个留出，每条主轨迹 2400 步。第 400 步是唯一主检验。

| 已观察到的结果 | 当前解释 | 仍不能推出什么 |
| --- | --- | --- |
| 稳定期 S=0.1258，95% 区间 [0.1194,0.1324]，128/128 为正 | 学得工具模型对行为有任务选择性的作用 | 新欲望、个人经历归属或价值标准已经形成 |
| 作用反转后，第 2000 步 S=-0.2314，120/128 为负 | 某些旧模型在该诊断任务中成为负担 | 所有旧经验都应被删除 |
| 晚期在线损失 0.3892，冻结模型 1.9665；变化前为 0.00842 | 持续更新有用，但本预算内恢复不足 | 已经获得可靠的持续适应能力 |
| 条件预测在主时点没有稳定优于同经历均值预测，后期更差 | 当前条件模型、数据覆盖或更新方式存在问题 | 状态条件建模本身没有价值 |

本次方案制定另检查了已有开发集的第 2000 步状态，没有运行新试验：32 个开发个体的 128 个工具模型中，9 个在改变后完全未重新访问；平均 62.04% 的样本来自变化前；最久的模型距上次实际使用已有 605 步。这些是解释线索，不是新的确认性结果。

正式数据曾有一份压缩轨迹尾部缺失，已用独立重跑结果按首次原有哈希恢复，完整审计与 11 项文件复现通过。新实现应继续保留校验、分段完成记录和异常记录。

## 三、源码给出的三个具体缺口

在上一轮冻结的 `core.py` 中：

1. 探索加成是 `0.15 / sqrt(1 + 累计访问次数)`。它记录用过多少次，没有表示最近一次验证距今多久，也没有表达当前条件是否受到这些样本支持。
2. 样本窗是每个动作最近被使用的 24 次，不是世界最近 24 步。不再使用某动作时，它的模型可以长期保存过时数据。
3. 没有样本时预测返回零变化。数值预测、未知程度和探索倾向没有被明确分开。零可以是计算所需的默认均值，但不能因此当作有证据支持的“没有作用”。

这些结构能解释为什么需要检查取样和知识时效，不能单靠读源码确定全部失败原因。条件外推、身体边界截断、样本混合以及单步协调也可能参与。

## 四、先辨别四种竞争解释

诊断优先使用已有开发轨迹与新开发种子。旧留出集已用于理解结果，不再用来确认新方法。所有诊断真值仅供评估器使用。

| 竞争解释 | 最小区分实验 | 结果怎样改变下一步 |
| --- | --- | --- |
| 没有取得足够的新证据 | 从同一检查点复制个体，安排等量实际取样；比较均匀取样、近期未访问取样与当前策略 | 若相同模型经新取样即可恢复，优先处理探索与覆盖 |
| 新证据已有，但旧数据妨碍更新 | 固定完全相同、按时间排序的真实转移流，比较现有窗口、按时间降权和局部更新 | 若同数据下更新规则差异很大，问题不能只归于探索 |
| 数据已有，条件模型仍预测不好 | 同一真实数据分别拟合均值与条件模型；拆分已见条件、材料插值、身体／疲劳外推与边界状态 | 如果简单模型在目标条件上持续更好，应保留它作为实际候选 |
| 预测足够好，协调仍不合适 | 在诊断副本用评估器的正确单步后果替换预测；必要时再给有明示特权的短视野规划参照 | 单步真值仍不足时，再研究规划与协调，避免误把所有失败都归给记忆 |

等量取样必须真实消耗原始动作和时间，不能把真值灌给普通学习方法。固定转移流实验只能识别给定数据下的更新能力，不能证明该方法会自主取得这些数据。真值参照不是一个公平学习基线，也不代表全局最优。

重放动作并不保证两条不同身体轨迹产生相同经验：需要研究“同数据更新”时，使用固定记录；需要研究“自主行动效果”时，让各策略承担自己的状态后果。二者必须分别报告。

## 五、先给模型增加可用的证据记录

对每个动作的预测，同时记录：

- 预测的后果及其来源模型版本。
- 最后实际验证的时间、有效样本量与样本年龄。
- 当前状态相对历史状态的覆盖情况。
- 更新前预测残差及其持续性。
- 当前选择是出于预期调节收益，还是给定的复验偏向。

覆盖范围、残差和样本年龄起初只是可解释指标，不能未经校准称为准确的概率置信度。条件模型的方差估计也不自动涵盖规律改变。

这些信息须真正改变选择或更新，才有功能证据；只增加日志不够。可通过禁用某项信息的作用，同时保留记录与存储，检查它是否承担了可定位的贡献。

本轮新增的证据监控、复验规则和阈值仍是给予条件。即使它表现出“怀疑旧预测”，也首先称为功能性的预测依据检查，不据此宣布反思、自我意识或内生欲望。

## 六、用小型对照组合检查改进来自哪里

主比较先保留原有四工具与 WAIT、理想点、透明预测族和基本评分，以便定位机制。新机会条件如需要一个备用通道，应从生命起点就向所有方法提供同一通道，其额外维度单列，不能在变化发生时凭空赋予某个方法新能力。两项主要改动分别为 E 和 U。

E：在原有决策中加入有上限的“距上次实际验证的时间”偏向。时间变长时允许重新尝试，实际取样仍收费；稳定世界下的额外代价要报告。第一版按动作记录，状态覆盖只作诊断，不同时引入多套复杂路由。

U：用更新前的持续预测矛盾触发局部旧样本降权／加快更新。第一版选择一种透明实现，在开发结束前确定，不在正式结果出现后更换。单次大残差不能自动等同于工具规律改变。局部清空作为机制参照，不作为必须采用的最终策略。

| 方法 | E：近期未验证促使复验 | U：持续矛盾触发局部更新 | 作用 |
| --- | --- | --- | --- |
| B0 当前基础版 | 否 | 否 | 保留已知基线 |
| BE 只改复验 | 是 | 否 | 检查新取样能解释多少改进 |
| BU 只改更新 | 否 | 是 | 检查没有主动取样时能改善多少 |
| BEU 两者结合 | 是 | 是 | 检查机制互补及额外复杂度是否有用 |
| BR 简单随机复验 | 固定小概率均匀尝试 | 否 | 检查收益是否仅来自多试了动作 |

BR 的参数只在开发阶段按预定规则选定。所有方法的总原始动作预算一致，同时报告工具调用比例、活动成本与计算量；总动作数相同不意味着实际主动取样次数相同。另做固定数量取样的诊断，对齐额外试探量，以免把更多试探误认为更聪明的试探。

五个方法使用相同的样本容量上限。若引入多个历史模型、回放或规划，须单列内存、更新次数和展开动作预算，再增加容量或计算匹配对照。第一轮不让多个专家的额外容量成为隐含优势。

## 七、世界至少覆盖六种不同情况

| 情况 | 必须观察的能力或代价 | 关键安排 |
| --- | --- | --- |
| 世界一直稳定 | 合理利用既有经验，复验开销有界 | 不安排必然到来的改变，不让代理一直等待“考试” |
| 原来有效的局部工具改变 | 取得反证并修订局部模型 | 主条件可将同一身体维度的正负工具方向对换，保留双向调节能力；维度与时点随机，不告知边界 |
| 一个少用工具悄悄变好 | 发现当前行为不会暴露的新机会 | 保持常用动作的反馈不变；可让初始已存在但作用很弱的备用通道变得有效，所有方法面对同一改变 |
| 暂时噪声变大，规律随后仍旧 | 对噪声保持稳健，避免破坏有用知识 | 噪声变化与动作规律变化分别设置，记录不必要的重置 |
| 可见疲劳／操作状态变化 | 将条件影响与规律改变区别处理 | 身体状态如实可见，工具映射不变；不将所有残差都解释成外界改变 |
| 旧规律 A→B→A 回来 | 衡量遗忘代价与重学／复用能力 | 回归时间不告知；第一版可能只能重学，应诚实报告 |

第三种情况不可省略。如果两种世界在当前所选动作下提供完全相同的反馈，只改变一个从不尝试的动作，基于现有反馈的错误检测就没有区分两者的证据。这是实验构造的可观察性限制。重新取样承担的作用与出错后的修正不同。

机会由预先固定的规则产生，不根据正式候选方法是否获胜来修改。若借用一个共同前缀来定义“少用动作”，选择必须发生在方法分支之前；后续所有方法面对同一机会，不能每个方法单独获得一种量身定做的世界。

尤其要检查可达性：当前每个身体维度只有一正一负两个工具，单独翻转其中一个可能消灭一个调节方向。主条件采用同维度对换可避免这一结构性问题。备用工具的改变也要用评估器参照检查实际收益，不能把“出现新数值”直接当作新机会。六类世界不做无意义的全笛卡尔组合；每类承担一个清楚的辨别问题。

## 八、正式验证应怎样固定

这部分是拟议规范，不是已经冻结的承诺。

### 时间与样本

- 可沿用每个个体 2400 步的有限生命，使前后研究有一项共同预算。
- 首次变化可在第 800–1200 步之间由独立世界随机流抽取；正式代理不接收变化时点、类型或任务边界。
- 主要评价窗口建议为变化后的 512 步。A→B→A 中第二次变化可间隔 600 步，仍保留完整的后续窗口。
- 新开发与正式种子完全分离，并与已有研究用过的种子命名空间区分。正式 N 根据新开发的配对变异、最小有用效应与资源上限确定；128 可作估算起点，不能预设统计把握度。
- 若在事先资源上限下仍达不到计划精度，应在留出前注明；不得看完正式结果再追加种子或更换主窗口。

### 唯一主比较

建议把主问题定为：在未知时点的局部工具变化后，BEU 是否比 BE 更好。这样直接检验“额外的知识更新机制”是否比简单复验带来更多价值。

令 L 是变化后 512 个动作后的身体平方损失均值；每个种子贡献一个配对差 `Δ = L(BE) − L(BEU)`。正值有利于 BEU。所有失败、迟迟未恢复的个体均计入。

初始工程讨论值可用最小有用效应 0.02、稳定世界容许增加损失 0.002。这些数值与当前量级有关，只是设计者的工程判断；新世界可达性校准完成后、正式运行前必须定稿并解释，不能在留出之后放宽。不要把它们称作自然规律或人的发展标准。

主效应需要区间支持事先指定的有用改善；同时通过稳定世界的代价约束。噪声条件下的不必要重置、身体条件变化下的误判及回归世界的遗忘代价完整报告。若主效应成立而代价约束失败，应称为有代价的取舍，不能笼统宣布更好。

统计抽样仍以独立种子为单位；同一基础世界跨方法、情形和分支的结果保持成组。多情形平均如用于总结，权重在正式前固定，并给出各情形结果，防止平均值掩盖退化。主比较之外的区间标为次要／探索性。

### 次要指标

- 累积损失与活动代价；最后一段稳定程度。
- 重新尝试相关工具的延迟、取得足够新证据的延迟、修订预测的延迟、行为恢复的延迟。它们不合并成一个不透明分数。
- 已选动作和未选动作的预测误差；实际状态与匹配诊断状态分别报告。
- 样本年龄、有效样本量、条件覆盖、连续矛盾与不必要的模型重置。
- 恢复时间若超过观察期，标为未恢复／右删失；不能只计算成功者的平均恢复速度。
- 如使用一步真值参照，称为一步参照差；未经动态最优策略证明，不称全局遗憾值。

### 开发纪律

先检查世界是否有信息、目标是否可达、对照是否可区分，再评价候选方法。保留所有试过的设置与代码修订。算法、参数、比较、预算、指标和分析脚本在新留出前一起冻结。正式数据不用于重新挑选检测器或场景。

## 九、补一条正向形成链，而不仅是删除测试

上一轮说明拿走学得模型会改变行为。下一轮还应跟踪：某次实际复验带来了什么新证据，它通过哪次更新改变后续选择。

可在诊断副本中比较：接受同样的新转移后正常更新；记录转移但阻断对应模型更新；只阻断无关模型更新；恢复那次实际更新。对齐当前可见状态仅发生在诊断副本，主轨迹持续运行。保留新证据的来源、更新前预测、更新量和后续选择。

若阻断对应更新使行为改善消失，恢复后重新出现，就能更具体地说明“这段新经历怎样参与纠错”。它仍是学习机制证据，不自动解释经历归属、主动反思或价值形成。

## 十、何时进入历史复用与情境区分

A→B→A 会暴露局部遗忘的代价。若第一轮证明复验与更新有独立贡献，而且回归规律仍需完全重学，下一轮才进一步比较：一个持续覆盖的模型、容量匹配的快速／慢速痕迹、有限数量的情境模型。

旧记录可以被保留而暂时不用于当前预测。适用范围要由可观察证据选择，不能向代理直接输入 A、B 标签；也不能每次出错就无限增加模型。若不同情境在可获得观察和探测动作下无法区分，需要承认不确定性，不能假定总能判定当前属于哪一种。

情境分类、模型路由、知识保留与更新成本都列为待验证机制。模型集合增加并不直接等于世界理解更深。

## 十一、把工程结果接回物欲的形成问题

我建议同时维护一份解释账本：

| 形成问题 | 本轮能提供的内容 | 后续仍欠缺的证据 |
| --- | --- | --- |
| 经历为何影响当前选择 | 具体作用模型与使用条件的变化 | 超越单一工具任务的迁移与历史效应 |
| 怎样修订过去判断 | 复验、残差、局部更新和新的行动后果 | 功能修正怎样支持更复杂的自我改变 |
| 怎样形成新的能力 | 当前只有给定原始动作的作用学习 | 序列的发现、复用、组合和公平预算下的优势 |
| 怎样出现新追求 | 本轮固定理想点和目标内容 | 由新能力支持的新结果候选，及其评价来源 |
| 怎样形成独特关系与标准 | 当前没有伙伴或共同活动 | 特定互动的不可替代贡献，以及赞许与共同标准分离的证据 |
| 怎样形成体验与归属 | 本轮不直接检验 | 需要独立论证，不能从日志、记忆或预测准确率推出 |

修订机制完成一轮可判定验证后，环境应向一个有持续外部状态的小工作坊推进：动作能留下可保留的痕迹或中间成果；组合动作改变可达结果；个体可以重复、维护或修改既有成果。

首项形成实验可问：一个过去无法达成的结果，是否因实际练习形成的可复用动作序列而变得可达，并随后进入选择。候选结果须来自已观测或有可追溯生成规则的变化，不能研究者先写好成熟目标清单再称其形成。

技能宏动作展开后的每一步都计费；原始动作对照有匹配的感知、数据和规划资源。能够选择新手段或新中间结果，首先称为能力支持的目标内容扩展；最终评价标准是否变化另行检验。

工作坊中的“作品”“伙伴”“共同标准”可以是研究者的描述，初始代理是否已有这些概念必须单列。语言模型若以后作为伙伴或继承能力加入，其既有训练贡献也单列。目标是逐项减少未解释的前提。

## 十二、已有研究能帮我们什么

1. Sutton 与 Barto 的作者配套讲义在 Chapter 8 区分了旧路线被阻断与新捷径出现，并介绍依据久未访问程度增加探索的 Dyna-Q+。这支持把“无报错的新机会”作为必要对照。此处的 E 只借鉴时间敏感的复验思路，没有实现 Dyna 的模拟规划，不能直接冒称完整 Dyna-Q+。来源：[作者讲义，页 22–25](https://web.stanford.edu/class/cme241/lecture_slides/rich_sutton_slides/16-17-planning-and-learning.pdf)。

2. Adams 与 MacKay（2007）用最近变化以来的运行长度分布进行在线变化检测，并显式使用变化先验。它提醒我们，变化判断需要模型与先验，不能被说成从无条件中自动出现。此次核验摘要及原文的运行长度、hazard 部分，未做全文系统复现。来源：[Bayesian Online Changepoint Detection](https://arxiv.org/abs/0710.3742)。

3. Alegre、Bazzan 与 da Silva（2021）的 MBCD 结合变化检测与情境模型，处理检测延迟、误报及旧情境的复用。它提供竞争方法与设计参照；文中的理论性质依赖其统计设定，不能直接移植为本项目的保证。此次核验原文相关定义与方法段落，未复现其实验。来源：[Minimum-Delay Adaptation in Non-Stationary Reinforcement Learning via Online High-Confidence Change-Point Detection](https://arxiv.org/abs/2105.09452)。

这些工作说明复验、变化检测和情境复用已有研究基础。本项目应以问题辨别与形成解释的推进为目标，而非把常见算法重新命名为新的欲望理论。

## 十三、实际实施范围与完成条件

下一次进入实现时，范围建议限定为：

1. 新建独立研究目录，保留旧实验的冻结源码与证据。
2. 完成四种失败解释的开发诊断；同时记录当前模型的证据年龄、覆盖与矛盾。
3. 实现 B0、BE、BU、BEU、BR 五个透明对照及六类世界，先以小型开发运行核验可辨别性。
4. 固定主比较、稳定代价约束、正式预算及全部分析口径，使用新留出完成一轮验证。
5. 给出正向新经历更新的干预证据，报告所有失败、各条件代价和可复现数据。
6. 根据结果明确选择：若 BE 已足够，采用较简单机制；若 U 增加可定位收益，保留 U；若预测表示是瓶颈，转向同数据模型辨别；若正确预测仍不够，转向协调与规划。

完成标准是得到可定位、可反驳的机制结论，允许结论为“复杂机制没有额外收益”。一次阴性结果不能成为无限添加模块的理由。修复工作有明确的一轮边界，之后决定进入工作坊形成实验或修订被否定的具体假说。

最终方向是让经历既能稳定支持活动，又能在新条件下被复验与修订，并逐步支持新的行动可能、目标内容与关系。每一步分别交代给予条件、实际形成内容和仍然欠缺的解释。
