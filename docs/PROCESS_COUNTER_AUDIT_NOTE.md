# 过程计数的审计说明

在正式实验执行期间、尚未读取正式组间效果前检查了指标代码。原始 `blocked_take` 和 `route_denied` 标记描述每个记录时钟上的动作请求；死亡后为了统一吸收态损失仍记录动作时钟，因此原始汇总可能包含没有身体执行的死后请求。

不更改已冻结的运行实现、原始记录、算法、首要身体损失、生存或停止规则。`tools/describe_whole_mechanisms.py` 新增明确命名的 `live_*` 计数，以前一步的 alive 状态筛选实际生命期间的请求。报告中的实际行为计数使用这些字段。冻结的 `analysis.json` 和原始 summary 保留，避免掩盖最初定义；它们的未过滤过程计数不作为能力证据。

状态干预中的动作差异也以两个分支共同存活的前状态筛选；身体损失差继续纳入全部固定窗口与死亡吸收态。该修正适用于所有条件、世界和方向，不按结果选择样本。首要比较仍对全部 64 个世界、两个初始化计分，没有增加或删除生命。
