# 完整体 1.1：机制与运行逻辑

这一版将新机制放进 `wuyu_unified` 的同一运行主干。`whole/A/B/C/D` 共享世界、身体、库存、旧图网络、经验技能记忆、神经后果预测、真实经历回放及 E/U；条件只决定新增动作通道和工作状态的形式。历史 `workshop_bridge` 与 01–08 等入口保持原语义，作为来源与回归参照。

## 一个时刻实际发生什么

1. 读取 21 通道局部观察，将当下确实看到的位置和需求写入旧经验记忆。
2. 旧图网络读取记忆、身体、库存和旧循环状态，产生七个原始动作概率；两类后果预测器分别预测七个动作，查询它们在此前真实经历中的样本年龄、数量和覆盖距离。
3. 修正后的组合策略以旧动作概率为基础，将短期身体、库存及**同设备**阶段变化的预测接入动作评分。此层保留已有固定混合规则，不宣称它是学习出的可靠性校准。
4. B/C/D 的动作适配器读取 378 个允许的特征，输出七个有限幅度的动作修正与身体回报价值预测。D 同时产生写入、保留和清除的连续门值。当前反馈还没有发生。
5. 用同一个体私有随机流的一次抽样选择原始动作。已有图网络状态推进一次；新增状态提交一次。
6. 世界执行动作，扣除真实行动成本和身体漂移，处理实际产物及预先安排的外生变化。只有此时才出现反馈。
7. 当前选中动作的真实后果更新神经预测器、真实前缀回放、证据模型及原技能记忆；误差历史供下一次决策读取。
8. 新动作模块接收实际身体匮乏奖励，每 32 步或死亡/声明终点做一次截断循环反传与 Adam 更新。未满 32 步的缓存进入存档，暂停不清空它。

评估器掌握的设备真值、事件类别、正确路线和分段成绩不进入第 1–8 步。`WholeWorld` 可以保存隐藏的物理状态和日程，代理的 `decision` 只接收可见观察及自身历史。

## 统一的进展语义

旧标签将“离开阶段 0 的设备、走到阶段 2 的另一设备”算作进展 1。新标签仅在移动前后属于同一设备时计算 `(after_stage-before_stage)/2`；位置变化单独记录。

六个预测目标依次是身体两维实际变化、库存两维实际变化、同设备阶段变化、是否出现产物。神经预测器仅对身体变化除以 0.28；证据模型保留原始身体单位。神经在线训练、回放和证据模型都使用同一语义修正，不只修改报表。实际身体收益、产品标记和操作阶段仍然分开。

## 四种条件

| 条件 | 旧循环状态与技能学习 | 新动作修正 | 新增状态 |
|---|---|---|---|
| A | 保留 | 关闭 | 无 |
| B | 保留 | 学习 | 每一步读取前清空，形成即时特征变换 |
| C | 保留 | 学习 | 标准 GRU 的持续状态 |
| D | 保留 | 学习 | 可写入、保留、清除的持续状态 |

B/C/D 均分配 22,120 个新增参数，隐状态维数 16、输入 378 维；优化规则及身体反馈相同。B 的循环矩阵虽分配，但由于旧状态始终为零不产生相同的有效循环能力，不能把参数分配相同说成计算和有效容量严格相同。C/D 的参数数目相同，算子略有差别；计时和更新次数另报。

输入包含原观察 21、上一动作/身体反馈 9、经验节点特征 186、依赖边 36、组合动作概率 7、两类后果预测 84、证据描述 21、历史实际误差 14。空间距离特征仍继承旧环形距离先验；通路受阻后它不会自动变成真实可达距离。这是当前整体必须面对的表示限制。

## 持续状态是什么，以及它还不是什么

令 `c = tanh(Wc x + Rc h + bc)`、写入门 `u`、清除门 `e` 为可训练函数，D 的状态为：

`h_next = (1-e) * ((1-u)*h + u*c)`。

C 使用同参数量的 GRU：重置门在候选内容的循环输入上作用，`h_next = (1-u)*h + u*c`。B 使用 D 的变换，但输入历史状态置零。所有门都只从允许的输入与本个体历史计算，没有设备目标编号或正确子目标标签。

这些变量没有预先赋予“我要哪一种东西”“这是尚未完成的承诺”等语义。当前实现提供的是一种可学习的状态组织；只有真实行为和选择性干预能够支持进一步解释。直接保留系数也不等于整个网络的记忆寿命，因为候选内容仍有循环路径。

## 动作学习的评价结构

奖励为实际下一状态的 `-sum((1-body)^2)`；死亡后的损失固定为 2，死亡价值尾部为 `-2/(1-gamma)`。这是公开给定的身体维持评价，不是新生价值标准。

最终参数：折扣 0.98，GAE 0.95，块长 32，学习率 0.001，价值损失系数 0.25，旧策略 KL 系数 0.01，熵系数 0.001，动作修正逐项为 `2*tanh(raw/2)`，梯度范数限 1，优势限幅 ±4。限幅会带来估计偏差，属于实现边界。输出头初始为零，因此最初动作概率恢复修正后的 A。价值初值是当前可见身体匮乏保持不变的估计；它不改变实际奖励。

只训练真实轨迹，无模型想象展开、教师动作、最优路径或子目标奖励。旧图策略权重保持不变，原经验技能、预测器和新动作模块在线学习。每个正式生命的动作模块重新零初始化；开发并未训练出可迁移的强动作控制器再投入正式世界。因此本轮评估的是给定短生命预算内的在线适应，而不是充分预训练后的能力上限。

这里的无教师指本轮在线过程。继承的 07/08 图策略已有教师训练史，这段来源没有因新实验而消失。

## 连续世界与评价

每条正式生命 2,560 步。t=0..1023 是熟悉与两类前置物角色机会；t=1024、1408、1792、2176 开始四个固定挑战窗口，依次包含前置依赖、新的通路/配方障碍、身体需要中断、局部收益消失。身体和库存不为子测试重置，损耗从现有余额扣除。每次障碍都保留物理可行替代途径，并在运行前检查依赖无环及已知配方的成本上界；这不保证自主个体已经发现路线或始终有足够余额。

稳定环境单独作为旧能力保护条件。所有条件的物理时长相同；不能把额外计算虚构成身体消耗。原始记录保留各步身体、动作、概率、预测、门值、目标、证据描述、成本及外生损耗。身体账本为 float64；大体积概率、状态与预测存为 float32，完整存档仍保留原 dtype。

首要统计以世界为独立单位，在同一世界内先平均两个固定旧模型初始化，再计算条件差并对世界做 bootstrap。失败个体和死亡吸收态全部计入；动作次数、诊断分支、时间步都不是新增独立样本。

## 存档、迁移与诊断

完整存档包括世界日程、身体、库存、原图状态和技能历史、两个预测器、回放及其 RNG、证据样本、动作参数、Adam 矩、活跃状态、跨步缓存、误差历史和动作 RNG。源码锁防止静默跨版本加载。

`migrate-whole` 仅接受经过冻结 v1 源码验证的完整 `workshop_bridge/combined` 存档。移动动作的证据样本可精确重标并重拟合。神经旧权重已混合旧语义，因而重初始化，重标真实保留的 reservoir 后重放一次；活跃神经状态从保留前缀近似重建。身体、库存、原图网络及其状态、技能记忆和动作 RNG 保留。迁移清楚记录损失与重建，迁移前后不承诺相同随机未来；迁移后的同版本保存恢复仍精确。

状态读屏蔽和真实历史替换仅发生在评估分支。所有分支从同一完整父状态复制，父生命不接收分支反馈。精确恢复检查验证代码能够还原同一轨迹；它本身不是机制优越性的证据。现有历史供体没有已识别的目标语义，也不是严格等范数的无关扰动，所以本轮只做状态使用诊断。
