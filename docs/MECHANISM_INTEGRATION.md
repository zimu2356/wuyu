# 机制整合与运行逻辑

本轮任务是把物欲 1–8、此前整合工程和后续四轮实验放回同一张机制与证据图，接通可兼容的机制，并检验组合后的实际行为。不是把不同实验的通过率加起来。最终“由物理欲望形成的人”仍是研究目标，不是本次验收的已实现功能。

## 1. 当前共同运行的个体

`workshop_bridge --mode combined` 持有一个世界、一个身体、一个动作随机流、一套图网络与循环状态、一份关系/效应/技能记忆、一套私有循环后果预测器与历史回放，以及七个有限窗证据模型。全部状态随同一个绝对时钟推进。每次只有一个实际原始动作，包含付费的 WAIT。

七动作：左、右、按钮 0–2、取物、等待。世界有六个位置、两项身体储量、两类库存。需求权重 `(1-body)^2+.02`、动作集合、图结构和目标类型均是给定的。图网络曾经经过教师训练，生命期内图网络权重固定；运行时不调用教师或路径规划器。

这里的“目标作用”通过当前身体缺口、过去学得的物品效应和动作概率体现。没有把旧目标实验的路径搜索器装进图网络，也没有把一个没有独立增益的目标缓冲重新命名为欲望器官。

## 2. 每一个事件的顺序

1. 世界只交付当前可见的 21 通道观察。当前位置、局部阶段、局部需求、库存、身体和上一产物可见；隐藏按钮配方、未来变化时点和实验标签不进入决策函数。
2. 当前观察事实只入账一次。特征读取与候选预测均为纯读取，不能增加经验，也不能消耗真实随机流。
3. 固定图网络读取观察、历史循环状态和学得的关系/技能记忆，产生动作先验。两个后果预测器在反馈发生前预测七个候选动作。
4. `combined` 将两个预测器的短期效用按固定 0.5/0.5 混合，截断偏置到 `[-1,1]`，加上封顶的动作年龄复验项 E。预热 32 个实际更新之前不影响动作。混合权重未经本轮结果调优。
5. 同一个私有随机抽样决定唯一动作。真实世界执行动作，扣除身体成本，产生实际反馈；等待也推进世界。死亡为吸收态，存档不会复活个体。
6. 07/08 的关联记忆更新实际按钮转移、产物效应及真正完成过的操作技能。证据模型只更新被执行动作：对持续同向矛盾使用 U 降低该动作较早样本的权重，然后加入当前事实。
7. 私有循环预测器按实际动作推进状态、学习当前反馈；回放仅取更早完成的历史，用当前权重重算短前缀，当前事件最后才入库。回放不执行真实动作，不向环境索取假想标签。
8. 世界、身体、库存、所有学习参数、样本权重、隐藏状态、回放库、访问次数、检测器、随机流、事件游标和来源整体保存。

本轮 U 的 24 样本窗、岭系数、检测阈值、同向判据、连续次数、降权与冷却常数直接承接证据修订实验。输入从 6 维改为 22 维、输出从 3 维改为 6 维，属于明确的新映射；没有合并不兼容的旧权重。6×3 形态已与原实现逐步比较，包括真实修订触发。

## 3. 1–8 与后来实验怎样归位

| 来源 | 机制进入何处 | 当前结论与保留限制 |
|---|---|---|
| 01：价值记忆、学习率控制 | 经验影响后续动作的原则；原实验完整可续接 | 没有强行移植旧门控；给定价值函数不等于价值形成 |
| 02：消耗、维护、工具与 Q 学习 | 身体成本、库存、前置依赖进入工坊世界；原宏动作系统独立可运行 | 旧 Q 表与宏动作没有冒充新原始动作网络 |
| 03：私有循环感知、在线学习 | 私有循环后果预测器实际参与组合动作 | 任务、维度不同；旧感知权重与 Dyna 控制器保留为独立对照 |
| 04A：重算回放前缀 | `combined` 实际执行最多四个过去事件加当前事件的短前缀学习 | 从零隐状态重算，是截断近似，非完整一生重演 |
| 04B：隐情境、专家、观测 | 原实验完整保存并接统一生命周期 | 专家路由与付费额外观测尚未进入工坊；本次不称“全模块融合” |
| 05：私有随机流、经历与回放 | 全部新个体状态私有；循环预测器回放仅用实际过去 | 新数值随机序列不冒充旧 xorshift 序列；复杂门控无默认必要性 |
| 06：身体、后果、目标池、付费回放 | 身体储量限制活动，后果学习改变动作偏置 | 原目标池与用身体支付的回放仅保留旧实验；组合计算成本另计，未从身体收费 |
| 07：经验模型、物品效应、动作技能 | 168 个关联参数、技能来源与有限经验实际在线更新 | 教师仅用于旧离线训练；本轮另设从出生冻结关联学习的消融 |
| 08：关系图、循环动作、需求 | 图网络作为动作组织骨干，读取身体与经验关系 | 图网络权重固定；不能把短期偏置称为整体行动结构持续可塑 |
| 旧整合版 | 世界、状态、记忆、图网络、前缀预测器作为可核验来源 | 原版学习无生存增益、长依赖失败的结论继续保留 |
| 目标形成实验 | 归入“学得后果 + 给定调节准则”的机制解释；原五变体四情境完整运行 | 删除目标缓冲行为相同；没有证明新欲望或新评价标准 |
| 自主探索实验 | 采集经历可移交同一学得模型作隔离评估；保留低预算探索证据 | 原采集每步重置身体，不能伪称连续生命；其 BFS 探索器不直接移植 |
| 持续经历实验 | 完整连续状态、WAIT、预测先于反馈、局部记忆干预、精确续接成为统一约束 | 两个世界的身体坐标含义不同，禁止混合身体损失数值 |
| 证据复验与修订 | 按动作保留证据、E 复验、U 局部降权实际接入工坊主闭环 | 原五方法六场景保持原样；原世界的成功不自动等于迁移成功 |

## 5. 必须保留的语义风险

- 工坊中的“局部阶段差”是数值代理：移动后看到另一设备的阶段也会改变它，不能等同任务进展。短期效用中保留的阶段项和固定混合尚待分离诊断。本次没有据结果修改它来让候选获胜。
- 两预测器的身体输出缩放不同，进入效用之前明确用 `.28` 对齐。混合后仍不保证校准；神经回放与局部 U 可能对旧经历保留不同强度。
- E 只读动作年龄，覆盖距离仅作记录，不是可信概率。它未解决同一动作在不同位置/库存下的证据覆盖问题。
- 后果预测 1 步、目标效用给定、图网络固定。复杂依赖仍需当前网络自己组织，不能由“组合成功取物”推断任意深度规划。
- 计算额外开销如实记录，尚未把它转成身体负担；存活指标未包含硬件资源竞争。
- 完整存档解决有限实验中的因果续接，不构成人格同一性或主观体验的证明。

## 6. 整合后的预期如何检验

先检验实现：131 项原测试、22 项新测试、所有输入文件哈希、五方法六场景既有原始轨迹的逐字段一致性。再检验实际行为：32 个未用于本轮调参的世界种子、8 个条件、3 个场景，每次 1,536 步，全部保留；不把同一时刻和诊断分支计成独立个体。

场景为固定简单世界、只改变一处按钮配方、旧完整发展世界（含依赖、规则变化与身体冲击）。度量实际存活、身体匮乏、成功取物、缺物仍取的受阻行为、机制实际更新和实际改动作次数。组合 vs prior 的不退化筛选在看结果前固定。详细结果与未达到的预期见根目录报告。

验收的目标是回答“哪些已接通、哪些对行为有作用、组合是否保持或改善原能力”。新欲望、新价值、成熟世界理解、长程自我改造与社会关系仍没有被本轮实现或测量。
