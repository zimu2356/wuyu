# 整体行动学习：正式评价前的开发决定

2026-10-12。此文件在首次读取正式评价结果之前写入。

开发 v1 使用 1300000–1300003，两个既有图网络初始化，A/B/C/D × challenge/stable，共 64 条生命。四组在稳定环境均为 8/8 存活，在挑战环境均为 0/8。D−A 的挑战身体损失为 +0.154281；新状态没有可靠收益。实际轨迹显示，通路受阻后重复尝试旧方向是主要失败形态之一，且动作修正幅度尚未接近限幅上限，不能简单归因为限幅截断。

一次开发期修订采用当前可见身体匮乏的常量持续估计作为价值初值，即 `V0 = -sum((1-body)^2)/(1-gamma)`，并将动作学习率从 0.0003 提高到 0.001。实际学习奖励仍是下一时刻负身体匮乏；价值初值不是正确路线或子目标奖励。两项设置作为一个开发版本测试，未单独识别各自贡献。

开发 v2 使用独立种子 1300100–1300103，仍为 64 条生命。challenge 存活为 A 4/8、B 2/8、C 3/8、D 3/8；平均身体损失为 A 0.707785、B 0.575031、C 0.631183、D 0.595733。所有组 stable 均为 8/8。D−A 的世界配对差为 −0.112052，95% 描述区间 [−0.716242,+0.314334]，四个世界的配对标准差 0.600511。两轮的世界不同，不能把跨轮均值变化当作修订产生的因果效应。

v2 中实际完成两类“令牌依赖另一令牌”经历的比例为 A 6/8、B/C/D 各 7/8。生成器保证角色机会出现，不保证每个自主个体都完成该经历。正式统计继续对所有个体计分，并报告实际覆盖率；不得据此宣称训练覆盖混淆已经完全消除。

保留 v2 作为正式候选，停止继续调整。旧 v1、v2 的源码快照、冻结协议、原始轨迹均保留。默认主干使用修正语义后的 A，B/C/D 显式开启。

正式预设 64 个世界（1400000–1400063），交叉固定初始化 0 和 1，四条件、稳定和挑战两类连续环境，各 2,560 步，共 1,024 条生命、2,621,440 次主生命转移。8 个预先指定世界做 C/D 的两个时点诊断，各 4 分支 × 64 步。正式世界和角色映射与开发不同。

首要比较 D−A，首要指标为挑战 t=1024..2559 的平均身体匮乏，死亡为损失 2 的吸收态。最小有用下降 0.01，稳定能力保护阈值沿用身体损失 +0.02 / 生存 −0.02。其他比较为描述性，不作未经调整的多重显著性宣传。

以 v2 的配对方差粗略估计，95% 区间半宽 0.05 需要约 555 个世界，半宽 0.02 需要约 3,464 个世界；小开发样本本身也使这个估计不稳定。当前固定的 64 世界预计半宽约 0.147，是资源限定的效果刻画，不能称为已充分检验 0.01 改善。无论方向、显著性或死亡数如何，不按正式结果加种子、调参或排除失败世界。

诊断使用完整父状态、32 步新状态读屏蔽、真实匹配历史状态替换、清除后立即精确恢复。所有诊断分支固定动作参数，已有物理经历学习继续。历史供体只在位置/设备阶段匹配并按观察距离选择，不能保证语义无关或等扰动范数。因此诊断只能检验新状态是否被使用，不能单凭它证明目标内容的选择性因果作用。
