# 正式实验前补充：直接神经控制

工程 pilot.json 显示 full/no_skill 行动成绩完全相同。这是确定性两阶段操作下两种控制途径的冗余，不能把技能被调用当成增益。

增加 neural_student 条件，以混合控制器的自身经历数据训练直接循环动作核心。训练目标是教师基于过去证据作出的动作，不包含真实按钮、隐藏产物图、阶段编号或未来信息。正式运行时只有神经动作输出，无教师查询，无递归依赖规划；继续在线更新 168 个关联与技能参数，循环动作核心权重固定。不能称全部神经权重的终身学习。

先验来源明确：教师带有设计的规划算法，神经核心经模仿学习获得这一控制偏好，不是从零自主发明规划。有限 softmax 记忆的坐标与身体价值仍有工程先验。

配置：三个初始化 701/702/703；32 个并行教师个体，512 次更新，每次 32 事件；H=32、输入 105；Adam lr=.002；每 256 更新保存并在原独立验证世界评估，按生存/身体面积选点。训练世界 760000 + 初始化索引*1000000 + 出生批次*32 + 个体索引。每个运行 524,288 个教师事件。原 RNN 参照是 actor-critic 而非模仿，参数、数据、外部记忆不严格匹配，不据此归因优劣。

主五个门槛仍针对混合个体的机制诊断。学生的自主连续生命、保存恢复、实际学到的操作、预测精度、以及冻结其关联学习的配对干预分别报告。学生没有强制设备目标接口，不能拿混合体的受提示操作测试成绩冒充学生成绩。
