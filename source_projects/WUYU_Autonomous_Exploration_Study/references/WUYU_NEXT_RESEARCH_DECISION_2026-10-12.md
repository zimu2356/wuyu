# 物欲：下一步研究判断与实施草案

日期：2026-10-12，Asia/Shanghai。

状态：基于当前文件和源码核对形成的研究建议。本文件没有启动新实验，没有产生新结果；下文参数属于协议草案，尚未作为正式实验协议冻结。不得在后续交接中写成已经完成的能力。

## 核心判断

下一阶段应研究：同一个个体怎样通过自己取得的经历，逐渐形成可修正的世界理解、追求和行动方式，并改变以后会经历什么。

“有限自主探索”适合作为第一项受控实验，但它只回答经验怎样取得，不能代表价值形成、人格形成或最终物欲。应同时保留清楚的全局问题，并让每项小实验说明自己究竟缩小了哪个缺口。

目前最需要改善的是证据结构：能够区分表现来自初始设计、教学支持、实际个人经历，还是这些因素的共同作用。不是所有能力都必须从零形成；继承的能力应当有来源，新增能力应当有形成证据。

## 一、重新核对源码后的判断

1. 当前目标形成实验的 training_experiences 直接遍历全部位置—动作对，每对 12 次，共 432 条经历，并重置身体输入。当前位置、结果类别和图搜索算法均已给予。它验证给定条件下的选择机制，没有验证自主获得这些条件。
2. Learner.decide 在没有已观察的可达结果时停止。因此，直接让当前空白学习器运行，并不会产生自主发现。
3. 删除显式目标缓冲后表现不变。该结果限制的是这个任务中该变量的必要性，不能推成“所有持续追求都无需目标记忆”。
4. 旧统一工程的运行层调用既有图网络进行动作前向计算；运行中的在线更新发生在经验模型和后果预测器。主要动作网络并未在个体运行期间持续训练。
5. 旧整合报告记录了新预测器接入动作后未改善主要存活指标，且同历史的简单动作均值预测器优于其预测误差。此处是旧报告结果，本轮没有重跑。先查反馈目标、时间尺度和学习效果，不能直接归因于参数规模。
6. 新实验与旧工程分别提供透明的机制基准和较完整的个体状态工程。两者有不同用途，不必把各自不同的任务语义、世界和参数强行合并。

## 二、必须区分的四种进展

| 进展 | 具体含义 | 需要什么证据 |
|---|---|---|
| 自主取得经历 | 个体行动决定能看到哪些后果 | 相同交互预算下的发现、覆盖、学习与失败记录 |
| 新的目标表征 | 系统获得此前没有的结果区分或组合 | 候选表示变化能迁移、能预测、能通过行动检验；不能只数标签 |
| 评价的改变 | 对结果的评价关系随经历或共同活动发生可追踪变化 | 区分身体状态改变、收益估计改变与评价标准改变 |
| 改变后续自身形成 | 个体通过练习、工具、环境或互动安排改变未来倾向 | 改变条件的实际行动、后续学习变化，以及干预切断后的差别 |

当前原型主要涉及固定准则下的工具性价值学习与状态重估。没有理由将它称为后三项已经解决。

自主目标研究将目标的表示、生成、选择和达成区分开来，这支持我们把问题拆清楚；相关研究框架本身并不是人格或主观欲望的证明。[1]

## 三、每项实验都登记能力从哪里来

建议维护一份简短且随代码更新的前提说明，对重要能力逐项记录：初始给予什么、环境或他人提供什么、从经历学得什么、用什么干预验证。

当前首先记录：身体量及理想点、可观察位置、结果标识、原始动作、规划算法、探索偏向、重置规则、评价准则、学习规则、动作先验和教师经历。

例如，设计者赋予“优先尝试访问不足的动作”，可以研究这种偏向支持怎样的发展，但不能声称探索偏好完全从没有方向的物理过程自行产生。反过来，有初始结构也不使后续学习失去价值。问题是新增解释发生在哪里。

若使用已经训练好的语言模型，它带来的语言与文化能力属于继承条件；若使用真实伙伴的回应，其贡献属于环境和共同形成条件。不能全部记作个体在本轮自行学会。

## 四、第一项实验：撤掉代选经历，保留其余条件

### 研究问题

在相同有限交互预算下，由自身动作取得的经历，能否支持结果发现、作用估计，以及当前状态下的适当选择？定向探索相对随机探索的效果来自哪里？

这是经验获取实验，具有基准与诊断价值；即使成功，也不应长期停留在这个九位置世界中追求更漂亮的满分。

### 候选设计

| 项目 | 草案 |
|---|---|
| 世界 | 保留当前 9 位置、4 动作、两个已分割结果和确定性拓扑 |
| 初始知识 | 转移表、作用表、结果目录为空；动作集合与当前位置编码仍给予 |
| 数据取得 | 从起点开始真实行动，下一位置来自上一步后果；训练器不直接把代理搬到任意中间位置 |
| 随机探索 | 每步在四个动作中等概率选择 |
| 定向探索 | 仅使用已经观察的转移和访问次数；在可经已知路径到达的位置—动作对中优先尝试访问不足者，平局由独立随机流决定 |
| 教学参照 | 保留原来的平衡全覆盖教学；标明它拥有额外的位置控制权，不称为公平自主对照或数学上的性能上界 |
| 交互预算 | 建议 108、432、1,728 步，记录三个截面的学习曲线 |
| 开发与留出 | 建议先用 32 个开发种子排除实现错误，随后在代码与协议冻结后运行 128 个未查看结果的留出种子 |
| 统计单位 | 环境种子；同一种子的多个预算点和多个条件有相关性，不能各算一个独立世界 |
| 拓扑范围 | 第一项实验不改变拓扑；新种子主要改变标识、动作映射和噪声，不能据此声称新结构泛化 |

定向探索使用的访问偏向和路径搜索都属于给予的能力。若其计算较多，应记录计算量；相同环境交互预算不等于相同计算预算。

### 身体重置必须公开

为单独辨别“经验选取”的效果，第一项实验可继续把每次采集经历的身体初态设为旧实验的固定值，让作用样本可比较。位置保持真实连续，结果后返回起点仍沿用旧环境规则。

这种条件下只能声称自主取得经历，不能声称连续生活。撤掉身体重置、使状态后果持续累积，是后续单独研究的问题；不得在同一次实验中暗中改变这些条件。

### 评价方法

记录两个结果各自的发现率、发现所需步数、状态—动作覆盖、作用估计误差、适当目标选择、成功步数、循环、停止和未发现结果的失败。

所有种子进入主要统计，未发现目标者不能从分母剔除。可额外报告“已发现两个结果者”的条件表现，但只能用于定位瓶颈。

在预算截点复制学习状态进行测试，测试经历不回写原训练支路。当前状态改变和饱足条件首先测试新反馈之前的选择；阻断条件允许按统一规则在失败反馈后学习，明确记录其额外测试预算。冻结知识的测试和允许继续学习的测试分开报告。

对同一批采集后冻结的经历，可训练 learned、no_goal_buffer、cached_value 等不同决策器，分辨“取得的经历不同”和“使用经历的方法不同”。两个自主采集者产生不同数据是闭环效应，不能冒称它们获得了相同经历。

### 按结果决定下一步

| 观察到的失败 | 下一步应辨别什么 |
|---|---|
| 经常看不到第二种结果 | 可达性、探索偏向和预算，而非先增加价值模块 |
| 发现了结果但作用估计不可靠 | 样本数、噪声、不确定性和估计规则 |
| 作用估计准确但选择或换路失败 | 决策与控制机制 |
| 两种探索表现相近 | 如实报告没有优势；检查环境是否太容易，不能为了赢而只挑条件 |
| 加目标缓冲仍无增益 | 在当前任务中保持简单实现；需要研究目标保持时，再加入中断、竞争与延迟 |

学习进展可以作为后续探索偏向的候选。已有研究给出具体实现，并将其与单纯追逐不可预测性区分。[2] 当前第一项实验无需同时堆入新奇性、信息增益、学习进展等多种奖励；先保留可解释的基线。

## 五、下一阶段的主线：同一个体的持续发展

第一项实验结束后，逐项撤掉支撑条件，而不是一次把所有难题压进同一个大环境。

| 后续问题 | 建议改变 | 保留的关键对照 |
|---|---|---|
| 经历能否持续改变行为 | 连续保留状态；环境规律反复变化；允许有限的动作学习 | 固定动作先验、简单状态—动作学习器、同历史的学习对照 |
| 学得是否越来越慢 | 经历多个可比的变化周期，记录适应曲线 | 旧知识保持与新知识学习速度分别衡量 |
| 新技能怎样扩展目标 | 从实际操作中获得可复用技能，扩大可达结果组合 | 相同经历、不同技能可用性；不直接提供完整新目标清单 |
| 对象怎样获得区分 | 逐步撤掉现成对象类别，检验变化中识别与跨情境迁移 | 预分割表示、学得表示、被打乱但容量匹配的表示 |
| 持续项目怎样组织行为 | 延迟结果、临时中断、手段失效与重新开始 | 逐步重估、显式目标保持、习惯；匹配可用信息与资源 |
| 关系怎样参与形成 | 接入简单可回应伙伴，共同操作和局部约定 | 实时互相回应与匹配输入量的回放；承认时序与可控性仍可能不同 |
| 个体怎样改变未来的自己 | 可选择练习、工具、环境布置或互动安排 | 切断这些行动对未来学习条件的影响，比较后续行为 |

持续学习要同时考虑遗忘和可塑性下降：前者是旧知识表现变差，后者是学习新东西的能力下降。相关研究在其测试环境中观察到二者的区别；它没有为物欲提供现成的永久学习保证。[3]

这里列的是研究问题及实施次序，不是规定人的自然形成必须经过固定阶段。

## 六、一个值得贯穿研究的具体情境

可以逐步发展一个数字工作坊：个体能够操作材料、使用工具、保留作品、练习技能，并与另一个可回应者共同活动。

早期只研究几个明确的作用关系；随后检验技能改变是否带来新的可想象、可实现的结果，再研究中断后的项目继续、共同约定和对自身做法的修改。

例如，某个个体偶然学会一种组合，开始重复和变化它；获得新工具后改变作品计划；伙伴改变回应方式后，它调整合作；一次失败之后，它选择先练习某个环节，再回到原项目。这是需要解释和检验的发展案例，不是系统应被脚本强制演出的剧情。

评价时同时问：发生了什么能力变化？哪些理解在改变？它为什么选择这个项目？失败使哪项知识改变？伙伴贡献了什么？后来的行动又怎样改变了未来能学到的内容？

不能简单地奖励“继续创作”“坚持”“合作”，然后把这些被直接奖励的表现当作自主关切的证据。也不应要求所有探索、关系和创造都先解释成饥饿或生存分数。

数字身体可以先定义为实际感知、作用与承受后果的条件。在建模世界中，一个状态若会改变可行动作、可获得信息或恢复速度，便有明确功能作用；如果它只进入评分公式，应按其实际用途命名。宿主 CPU 占用、复制或在线时长本身不等于欲望、繁殖需要或身份连续性。

## 七、价值形成需要更严格的提问

身体状态改变后选不同结果，是状态重估；知道原先有益的东西现在有害，是后果模型修正；改变何种事情值得追求，则增加了对评价标准形成的解释责任。三者不能用同一句“价值变了”混合。

当前最可检验的候选方向是：某对象或活动通过共同经历，逐渐参与多个后续计划、技能和关系，从而改变其在未来行动中的地位。需要与熟悉度、累计收益、即时吸引和外部赞许等更简单解释比较。

这些对照必须限定各自允许的输入、学习历史、计算资源和可变参数。不能给一个简陋基线过少信息，再将胜出称作“超越奖励”；也不能事后为任意行为添加一个隐藏奖励，使解释永远不会失败。

功能性评价、自我解释和主观体验依旧有不同的证据要求。可以检验前两者的形成机制，同时保留体验问题；不应以此取消研究，也不应提前宣布体验已经出现。

## 八、对旧工程的具体处置建议

保留归档与来源，不重写旧结果。优先借用其保存恢复、独立随机流、分支与反馈时序方面的工程实现；当前表格实验继续作为透明基准。对动作网络、经验记忆、回放、图结构等机制，按新问题逐一决定是否使用。

01—08 统一入口已存在。进一步的整合价值应来自共同的观察—行动—反馈约定、状态来源和评估方式。历史上不同世界的特征维度、动作和权重没有天然兼容性。

0 阶段原包缺失继续记录，但不必阻塞当前可核验材料上的研究。不得把不存在的源码补写成历史恢复。

模型规模由待承载的机制、数据需求和运行预算决定。在小型实现中尚未辨别经验采集、表示、控制和学习瓶颈之前，没有依据把它们统一归结为模型不够大，也没有依据承诺 0.几 B 一定足够。

## 九、实际应交付的下一组成果

1. 前提与来源说明：哪些结构给予、哪些内容学得、哪些由他人或环境提供。
2. 有限自主探索的正式协议：采集规则、重置条件、预算、开发与留出种子、评价时允许的学习，以及失败报告方式。
3. 独立实验分支：保留旧基准，记录全部采集经历、状态快照和失败；不先改写整合工程默认行为。
4. 按采集、估计、选择与控制分解的诊断报告；结论必须影响下一步机制选择。
5. 面向持续发展、目标表征与共同活动的后续问题表，每项注明尚未实现。

这组交付的完成标准不是一张高分表，而是能够更准确地回答：已有表现由什么条件支持，自己的经历新增了什么因果作用，接下来应撤掉哪项支撑或修正哪项机制。
