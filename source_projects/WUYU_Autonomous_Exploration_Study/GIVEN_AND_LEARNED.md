# 给予条件与学得内容

本研究只检验经验获取方式的作用。沿用第一轮目标形成实验的环境与学习器；没有把旧 01—08 神经工程当作最终架构。

| 条件或能力 | 来源 | 本轮是否研究其形成 |
|---|---|---|
| 9 个位置、4 个动作、固定世界拓扑 | 设计者提供 | 否 |
| 精确位置与结果标识 | 环境直接提供 | 否；没有对象或符号学习 |
| 二维身体量、零理想点、平方偏差准则 | 设计者提供 | 否；没有价值标准形成 |
| 每次采集前身体重置；结果后返回起点 | 实验支持与原环境规则 | 明确保留；不能称持续生活 |
| 已观察转移表与结果作用均值的更新规则 | 继承算法 | 内容由实际经历更新 |
| 结果目录初始为空 | 继承机制 | 实际观察后才增加；世界结果类别仍预分割 |
| 基于已观察图的最短路搜索 | 继承算法 | 否 |
| 均匀随机探索 | 本轮提供的采集规则 | 否 |
| 访问不足优先与相同次数下较近位置优先 | 本轮提供的采集偏向 | 否；不称无偏物理过程产生的好奇心 |
| 全覆盖教学的任意位置控制权 | 仅教学参照拥有 | 不属于自主代理能力 |
| fixed_target 的 A 身份 | 实验者给予的对照例外 | 其他学习器、采集器不读取 |
| 正确结果与真实作用 | 仅评估器读取 | 不反馈给采集器或决策器 |
| 个人经历序列 | 采集策略与环境共同产生 | 本轮主要研究对象 |

同一采集轨迹的不同决策版本获得相同经历；不同采集策略通常产生不同经历，这一差别是闭环的一部分。相同交互预算不等于相同计算预算，定向采集的搜索开销需单独记录。

没有生存惩罚、痛苦变量或死亡假设。身体量是模拟输入，宿主资源不被解释成主体需要。没有语言模型、预训练权重、网络服务或后台持续运行。
