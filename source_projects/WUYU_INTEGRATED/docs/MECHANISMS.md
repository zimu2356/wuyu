# 机制整合清单

本清单依据当前恢复到的 01—08 源码。原来的源码用于学习、追溯、对照，不决定物欲最终必须长成什么样。

| 来源 | 机制与代码 | 本次去向 | 不能越过的结论边界 |
|---|---|---|---|
| 01 | 价值记忆、误差统计、固定/自适应学习率：`wuyu/core.py` | 原版 `01` 档案统一运行与存档；门控作为独立假说保留 | 无法把学习率变化本身解释成欲望；新主闭环没有移植该门控 |
| 02 | 工具消耗、维护、Q 学习：`wuyu02/workshop.py` | 原版 `02` 档案；外生流纳入完整存档 | 原动作是宏动作，不与 08 的按钮原始动作混同；Q 表未移植 |
| 03 | 私有循环感知权重、在线梯度、Dyna/经验控制：`wuyu03/core.py`、`neural.py`、`control.py` | 原版 `03` 完整保留；私有循环学习原则推广为新后果预测器 | 是新训练任务和参数形状，未合并旧权重；Dyna 控制器仍为独立对照 |
| 04A | 陈旧隐藏状态与重算前缀回放对照：`wuyu04/diagnostic.py` | 前缀重算机制接入新预测器；原实验保留 | 新前缀长度 4，零状态截断近似；并非无损重算整个过去 |
| 04B | 隐情境信念、专家槽、主动观测：`wuyu04/latent.py` | 原版 `04` 可运行、可保存恢复的独立世界 | 还未与身体世界共同工作；原主动观测决策并未完整按成本优化 |
| 05 | 私有随机流、回放库、学习率公平对照：`wuyu05/core.py` | 新个体独立持有随机状态；实际过去的 reservoir 回放接通；原版 `05` 保留 | 新流用 NumPy Generator，未复用旧 xorshift 数值序列；旧实验不支持默认启用复杂门控 |
| 06 | 身体稳态、在线行动后果预测、经验目标池、付费回放：`wuyu06/agent.py`、`world.py` | 身体后果影响动作原则接入新主闭环；完整原版 `06` 可运行 | 原经验目标池和以行动支付的回放未接入新闭环；新回放消耗计算，未从身体余额收费 |
| 07 | 经验转移、物品效应、完成动作后获得技能、神经学生 | 新经验记忆沿用 07/08；规划方法从新运行类删除；原版 `07` 保留 | 环形距离、节点编码仍是工程先验；教师曾用于离线训练；技能独立增益未由本整合重新证明 |
| 08 | 关系输入、循环图网络、神经原始动作、身体需求干预 | 新主闭环使用已训练图网络；特征纯读取、独立随机流、迁移/分支/完整恢复 | 图网络动作权重目前固定；新可塑部分为后果预测器；长链能力仍待证明 |

统一工程解决接口、生命周期、追溯和可比较实验。它没有把八个不同世界硬塞进一个观察向量，也没有声称每个旧模块已对同一个个体产生正收益。

## 新闭环的实际时序

1. 世界给出当前可观察位置、局部阶段、局部需求、库存、身体和上一产物。
2. 每个事件仅写入一次观察事实；特征编码本身不写入记忆。
3. 图网络与私有循环预测器读取实际过去；预测器枚举七个原始动作的短期可观察后果，不读取隐藏配方或未来。
4. 固定图网络给出动作先验；实验条件下，后果预测经过声明的身体价值函数调整动作概率。没有教师导航或路径搜索回退。
5. 世界执行唯一动作；个体才得到反馈。经验模型和技能按实际结果更新；实验预测器只用实际执行动作的标签更新。
6. 回放只抽取更早完成的经验，重算其最多四步前缀；随后才把当前事件加入 reservoir。
7. 世界、神经权重、循环状态、经验、随机状态、回放、游标及来源共同存档。

已声明的设计选择包括七动作、六站点、两身体量、物品类型、神经网络形状、身体价值权重、记忆容量和学习损失。它们提供了研究环境；当前系统没有自主发明这些结构。

## 为什么不默认打开所有模块

模块互相影响的因果链需要实验。更复杂的预测器可能不及简单统计，回放可能耗计算而不改善行动，隐情境分类可能错误拆分一个连续变化的世界。每个候选模块都要先回答：接收什么证据、改变哪个状态、通过什么路径改变未来行为、失败时如何定位。测试通过只证明某些实现约束成立，不能替代能力实验。
