# 正式数据前的神经学生修正

初轮学生验证显示教师轨迹上的逐动作准确率不足以保证自主连续生活。只使用训练和既有验证世界，增加一次固定预算的自身轨迹训练；不以正式结果决定训练。

从每个初始化的初轮最佳验证模型开始。512 次更新 × 32 事件 × 32 个体；前 128 更新以 .3 概率采用教师动作，其后全由学生采样动作。教师只读取当前学生自己的已学习关联模型、技能和局部观察，给出模仿标签；教师不能读取环境隐藏字段。所有实际反馈回写学生自身，教师不会替学生补充事实。

新训练种子 780000 + 初始化索引*1000000 + 出生批次*32 + 个体索引；每生命 1536 事件。H=32，Adam lr=.001；每 256 更新在 730000–730015 验证。候选包括初轮两个保存点和此次两个保存点，按相同生存/身体面积规则选择。所有原始训练和候选保留。此调整依据验证进行，最终验证成绩存在选择偏差；正式世界仍封存。

这一过程把手写规划教师的偏好传给神经策略，不能称策略完全从无教师的经历中自主产生。正式运行不再查询教师。
