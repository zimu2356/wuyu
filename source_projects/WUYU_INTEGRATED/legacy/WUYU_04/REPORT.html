这次真正推进了什么

已经做出可以保有旧规则、根据证据选择规则、再学习一种新规则的有限核心。同时找到了旧 RNN 回放流程中一个值得继续采用的改动：用当前参数重新走过样本之前的短段经历，改善回放状态的一致性。

这项进展属于未来持续个体所需的一个机制：经历新事情后，旧能力仍能被重新调用。它还没有构成你想要的完整“物欲”，也没有提供意识、人格、生命或成为人的证据。

关键负结果：主动探查切换得更快，但全程付出的成本超过了新增收益；观测可靠率下降时，它仍会混淆“规则变了”和“信息变差了”。

实验分成两层，不能混在一起读

A 层逐字复用 WUYU_03 的 1033 参数 RNN，将动作固定、线索可靠率设为 0.9，隔离表示和学习问题。B 层是一个独立的简化规则核心：8 种线索、二元答案、两个学过后冻结的模块，加一个可塑的新规则槽。B 层没有整合旧版的身体与工具控制。

A 使用 8 个验证个体和 32 个正式个体；B 使用另 32 个正式个体。相同个体跨方法共享普通事件与噪声。学习率在验证集上选出后固定；原网和双模块均选中 0.01，三档验证准确率各自相同，依协议取最小值。B 学习率事前固定为 0.2。

区间是以个体为单位进行 4000 次配对 bootstrap 的 95% 百分位区间，不把时间步当作独立样本；多个比较未做多重校正。

旧隐藏状态回放保留 A 的准确率为 73.1% [62.9%, 82.4%]；用当前参数重算最多 8 个前序事件后为 90.3% [89.7%, 90.8%]。配对差为 +17.18 个百分点 [+8.03, +27.25]，B 的准确率差为零。这次达到事前规定的收益门槛。

这是有限 burn-in 方案的实证收益。它同时改变了回放初始状态的时效性和有限历史近似，不能据此断言“所有遗忘都只由陈旧状态引起”。回放训练也多用了梯度计算，已用“重复当前样本”作额外计算对照。

把情境输入重复送入每一个微步，仍没有挽救顺序原网；它不是简单的“再提醒一次就行”。双模块把两套规则分开学习，接近噪声上限，但参数和执行工作量也加倍。

联合训练门槛没有通过。原网交错训练的 A/B 均值约 81%，但两项区间下界都低于 80%。严格逐次交错还可能让网络利用时序规律，而评估是分情境连续输入，存在分布差异。因此不能把这次失败解释为容量不够。同样 1033 参数的重算回放条件已经在无参数更新的 A/B 测试中达到约 90%，没有证据要求现在先扩大模型。

最终单次反事实探针中，仅交换情境而保留线索和当前隐藏状态，顺序原网答案翻转率为 0；重算回放为 62.5%；双模块为 100%。单次探针与连续 256 步评估不同：前者不允许状态经连续输入重新稳定，不能据其不足 100% 就断言规则未被存储。

隐藏情境：先学过，再凭证据找回来

学徒期 A/B 各 1024 次，允许提供情境标签；两个模块的答案均从作答后的反馈学得。进入隐藏期后，代理不再收到规则编号，依次经历 A → B → A → C → A → B → C → A可靠率退化 → A恢复，每段 512 次。C 在学徒期从未出现。

被动核心从普通反馈更新三种情境的信念；主动核心在信念较不确定时，选择模块意见最不一致的线索，付费请求一次带独立噪声的标定样本。该样本可能与当前线索相同，但不直接提供当前事件的目标，也不提供情境编号。

“旧返回”是阶段 2、4、5（从0起算）的平均，不能解释为每一次返回都超过 80%。主动条件首次 C 前32步只有 59.9%，末128步才达到 89.6%；它需要获得证据并学习，并非一到新世界就知道规则。

被动的旧返回区间下界是 80.05%，仅略过门槛；主动是 83.79%。所有三模块条件的 A/B 权重最终都与学徒期后逐位相同。这来自明确的冻结机制，不是自行发现的保护策略。冻结权重检查证明存储保持，隐藏期行为才检验是否能访问这些记忆。

主动探查：快一点，不一定划算

六个规则切换阶段前 32 步，主动相对被动提高 +4.17 个百分点 [+3.71, +4.64]。但每个体平均多请求了 622.66 次标定，占 4608 个普通事件的 13.5%。

每次标定事前定价 0.10；答对奖励 +1、答错 −1。主动相对被动的全程净收益差为 -0.00520 [-0.00748, -0.00293]，整个区间都低于零。不能把准确率改善直接称为自主探查策略已经更优。

可靠率退化段，主动条件在约 47.4% 的事件中继续探查，但准确率只有 54.2%；真实情境路由上界为 59.6%。这里的“传感退化”仅通过增大标签噪声模拟，没有独立物理传感器，也没有因果故障定位实验。

全部阶段结束后，无更新枚举八种线索：主动核心旧 A/B 映射仍为 100%，可塑 C 模块为 97.3%；被动 C 为 100%。因此“新规则学会过”仍不等于“之后始终完整保留”。本轮没有逐阶段 C 权重检查点，不能进一步定位是哪一段导致了最终偏差。

现在还不能声称什么

不能说已经形成通用模型基底、完整物欲个体或数字生命。这里既没有语言与真实多模态感知，也没有长期身体、自维护动机、社会学习、能力变化的自我模型，运行也是有限仿真。

三模块划分、两个冻结槽、一个可塑槽、真实标签学徒期、二元反馈反推标签、固定切换先验、探查触发策略，都是设计者提供的结构。代理学了具体答案和在线情境信念，但没有自行发现任意数量的新情境，也没有学会如何定价探查。第四套不同规则将超出这轮的预留设计，尚未测试。

A 的新回放机制尚未接回 WUYU_03 的完整工具世界；B 使用不同、更加透明的规则网络。因此这一版提供的是两个可继续整合的机制结果，不是声称所有旧功能已经在一个新个体里共同运行。

据这些结果，下一步应该怎样走

优先建立“观测可靠性”与“规则身份”的分离估计，再把通过的记忆机制接回持续环境。当前失败已经给出了具体方向，无须先把模型放大。

  1. 保留原始旧系统，单独接入当前参数的前序状态重算，在同一个身体/工具环境、相同交互预算下验证收益能否迁移。
  2. 在 B 核心中分别表示规则、观测可靠率和自身执行能力；让世界分别改变它们，并提供可区分原因的诊断动作。仅观察一次错误时三者可能不可辨，必须设计能产生不同证据的干预。
  3. 比较探查的预计价值与真实成本，让系统在继续试探、等待、换传感通道、修正模型之间作选择；不能只把“更不确定”翻译为“继续花钱探查”。
  4. 之后再取消预留第三槽，检验新增、合并、冻结与淘汰记忆；用未见过的第四、第五规则和组合任务验证，避免凭固定三槽成绩宣称开放式成长。

你希望的“物欲”最终需要这些机制与持续的身体、环境、动机和经历连在一起。本轮已经把“知道旧规则在哪里、何时该用它”的一部分变成了可运行、可复现的实验。
