本包包含可执行源码、模型和实际实验结果。先打开 REPORT.html 阅读完整中文说明。

## 先运行一个已有个体

需要 Python 3.10+ 和 NumPy；复现实验图表另需 Matplotlib。首次安装：

```bash
python -m pip install -r requirements.txt
python demo.py --steps 48
python demo.py --steps 64 --save continued_08.npz
python demo.py --checkpoint continued_08.npz --steps 64
```

默认恢复 graph_varied、初始化 0、正式生活第 384 事件的真实检查点，保留 32
个并行个体的完整状态，终端显示第一个。它在制作报告之前就固定为展示对象，
没有按正式表现筛选。程序执行期间才会继续活动；关闭后不会自动在后台生活。
超出正式 1,536 事件仅作探索性延续，不计入报告成绩。

## 四组对照

| 组别 | 神经结构 | 训练中的身体缺口 |
|---|---|---|
| flat_regular | 展平输入的循环网络 | 普通连续生活 |
| flat_varied | 相同循环网络 | 额外的需要变化 |
| graph_regular | 三轮共享关系运算 | 普通连续生活 |
| graph_varied | 相同关系网络 | 额外的需要变化 |

两种结构都使用相同的经历事实、依赖边、环形距离、可微子目标注意力动作解码器。
训练均有教师目标/子目标/动作监督，正式运行直接输出七种原始动作，不调用教师
规划或手写导航。参数 11,325 / 11,345；循环状态 30 / 240 标量，因此不能将
参数近似相等称为所有资源完全相等。图网络的结构差异包含对象分解与关系偏置。
身体资源消耗是模拟动作成本；额外内部计算没有扣除更多身体资源。
上面的参数量包含辅助目标读出；直接参与原始动作路径的参数分别为 11,139 和
11,304。辅助终极目标读出用于训练和诊断，动作解码器使用的是子目标注意力。

训练共享权重固定于正式生活前；生命中的 168 个关联/技能参数继续从个人反馈
学习。没有开放式概念增长、共享策略终身更新、显式未来身体轨迹推演或意识证明。

由脚本设置，训练器最多五个子进程。每个训练阶段与总墙钟时间随包附带。

轻量包保留源码、协议、全部选中模型、摘要及默认检查点；完整包另含全部候选、

含教师引导的知识获得，须与自主生活结果分开看。
