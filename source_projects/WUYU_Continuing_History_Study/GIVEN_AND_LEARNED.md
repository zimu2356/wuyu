# 给予条件与学得内容

本研究实现持续状态和针对模型记忆的干预。世界是低维工具控制环境，不是已经实现技能、作品或社会互动的完整工作坊。

| 内容 | 来源与边界 |
|---|---|
| 二维身体数值、零理想点、平方偏差 | 研究者给予的调节标准；不解释价值标准的起源 |
| 操作余量／疲劳数值 | 环境变量，实际影响工具幅度；不是感受的证明 |
| 四个不透明工具通道与 WAIT | 给予的动作集合；每个工具的方向、幅度和条件作用需学习 |
| 身体缓慢漂移与恢复 | 给予的环境过程，公开记录；没有痛苦、死亡或必须永远活动的奖励 |
| 位置、物体、结果类别 | 本轮没有空间导航或对象形成；传感器直接给低维数值 |
| 特征 [1,b0,b1,f,m,f*m] | 给定的模型基底，包含正确类型的交互；不能声称发现了物理方程结构 |
| 最近 24 次经历、岭回归、逐步更新 | 给予的可塑性规则；样本及系数由实际经历产生 |
| 调节评分、活动成本、访问不足偏向 | 给予的协调规则；本轮不研究协调规则自身形成 |
| 工具映射、具体身体作用 | 对代理隐藏，由经历学习；评估器可读真值 |
| 记忆删除和恢复 | 研究者对诊断副本的干预，不是代理主动自我修改 |
| 理想点及目标内容 | 全程固定；没有新增欲望、目标类别或评价标准 |

主轨迹每步承受后果，没有身体重置、训练／考试模式或在 WAIT 时结束。诊断副本才对齐当前身体、疲劳与材料属性。有限时长终止由实验预算决定，不作为死亡或失败经验。

外部日志不是代理的记忆。代理可利用的内容为有限样本缓冲、拟合模型、访问次数和随机状态。实验记录将来源事件 ID 与模型更新关联，另用干预检查这些内容是否有实际作用。

删除 axis0 或 axis1 对应的两个工具模型及其样本；WAIT 模型、其他工具模型、访问次数、协调规则和随机状态保留。固定参数容量相同；仅当四个工具缓冲都已满，删除的经历数也完全相同。未达到者照常保留并报告，不用筛选制造匹配。

恢复分支先执行 axis0 删除，再恢复原样本、矩阵与参数，核验整个代理状态逐字节等同于保留分支。这是可逆性和软件隔离检查，不增加独立的心理形成证据。

独立随机种子改变工具映射、作用参数和噪声；不等于新的物理法则族。材料 0.5 的诊断在训练材料 0.2 与 0.8 之间，属于给定特征下的插值，不称广泛泛化。
