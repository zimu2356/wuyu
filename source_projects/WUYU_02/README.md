# WUYU_02：校准、发育原型与反例检验

这是可实际运行、可复现的小型机制研究。它包含精确贝叶斯校准，以及普通 Q 学习控制的工具世界；不是语言模型、数字生命或意识实现。

## 本轮结果

- 四个校准门槛通过。
- 工具世界中：控制学习、历史分化及工具失效后的调整通过预设判据；依赖解除未达到预设幅度。
- 不同经历的个体在共同世界中，工具 A 使用尝试占比相差约 71.8 个百分点。
- 原优势工具失效后，在线学习比冻结模型的平均末段回报高约 0.248。
- 外部免费支持后，原优势工具维护率仅下降约 0.72 个百分点，未达到预设至少 3 个百分点。
- 这些现象由 125 个行动价值的普通 Q 学习产生，不支持独立于普通强化学习的新主体性机制。

完整解释见 `REPORT.html` 或 `REPORT.md`。包括全部标准、效应区间、数值问题修复及不能得出的结论。

## 运行

Python 3.12.14、NumPy 2.3.5、Matplotlib 3.10.8 上执行。安装依赖后：

```bash
python -m unittest discover -s tests -v
python run_experiment.py --output reproduced_results
python demo.py --history A --branch external_support --steps 512
```

`run_experiment.py` 拒绝覆盖已有实验目录。A 校准失败时不会进入 B。使用同一代码、版本、种子能重现本轮结果；换依赖版本时浮点舍入可能不同。

原目录 `results/` 保存最终主结果。`diagnose.py` 是主实验后的解析检查，拒绝覆盖既有诊断。其模型求解函数可单独导入；若要完整从头复现诊断，可在项目副本中保留原证据归档后生成新的默认 `results/`。`make_report.py` 根据默认 `results/` 生成图表与报告。

## 实际实现

- 校准：四种二值隐状态世界，真实答案不反馈给预测器；参考滤波器知道生成规律，不知道隐藏状态。
- 发育：两种可消耗的感知工具、基本感知通道、工具维护。环境只有五种宏动作，工具类别和奖励均预先规定。
- 学习器：25 个可见工具状态 × 5 个动作 = 125 个 Q 值；根据即时奖励与下一个状态的估值更新。最终选中步长 0.15、折扣 0.95、探索率 0.08。
- 128 对个体共享相同初态及配对外生随机表，分别接受 A/B 历史，之后进入共同环境与七个干预分支。
- 工具次数影响实际线索通道；没有生命条、死亡判据、情绪命名或人格提示词。

维护属于宏动作，感知线索解码器是预设的；不能声称所有行为或身体结构都是从零长出的。工具维护也不等于维护模型运行本身。

## 文件

- `PROTOCOL.md`：主实验前固定的方案。
- `AMENDMENT_01.md`：浮点饱和问题、修复范围与重跑记录。
- `SUPPLEMENT_01.md`：看到主结果后声明的解析诊断。
- `VALIDATION.md`、`tests/`：必要实现检查。
- `wuyu02/calibration.py`、`wuyu02/workshop.py`：环境、滤波器和学习器。
- `run_experiment.py`：选择、评估、区间、阶段门槛。
- `diagnose.py`：已知完整环境规则的精确动态规划参考，不是新的学习算法。
- `demo.py`：载入真实检查点，观察一个个体在干预后的运行。
- `results/`：逐轨迹数据、逐步行动与奖励、检查点、参数选择、日志、时间与源文件哈希。
- `archive/initial_run/`：数值修复前的代码和输出，保留审计，不作为最终证据。
- `CHECKSUMS.sha256`：交付包文件完整性。
